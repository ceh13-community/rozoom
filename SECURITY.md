# Security policy

## Reporting a vulnerability

Please use [GitHub Private Vulnerability Reporting](https://github.com/ceh13-community/rozoom/security/advisories/new). Do not open a public issue for a security problem.

## Supported versions

Fixes go into the latest published release. Older releases are not patched.

## How ROZOOM handles access and data

What the app reads, what it connects to and its known gaps are described in [dashboard-app/SECURITY.md](dashboard-app/SECURITY.md). What is collected and why is in [the privacy notice](https://rozoom.app/privacy).

ROZOOM Design System

a swiss army knife for kubernetes

An operations-grade fleet IDE for Kubernetes. Cross-platform — Tauri + SvelteKit on desktop, SvelteKit on mobile. Calm midnight navy + electric blue, with an amber-on-black K9s alt-theme for terminal lovers and a soft Light theme for daytime work. This page is the entry point — all surfaces use the same semantic tokens in colors_and_type.css.

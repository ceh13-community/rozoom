1. Score pill (44 × 44, --radius-lg)
The primary status signal. Color + numeric + glyph (✓ / ! / ×) so colorblind users still parse it. Mono 16/700.
2. Cluster name (15/600)
One line, no truncation budget — names like prod-aks-westeurope are real. Use min-width: 0 on parent if flexed.
3. Provider · region · cloud (mono 11)
Always in this order, separated by · . Muted foreground.
4. Status badge (mono 11/600 caps)
Mirrors the score-pill color. Shown ONLY when status differs from neutral. No tracking-wider — caps + mono is enough signal.
5. Divider
Single 1px border-top, 8px breathing room. Never a colored divider — that's the badge's job.
6. Metrics row
Bold numeric (mono) + dim label. Order: nodes → pods → deploys. Optional 4th: alerts.

Do / Don't

DoColor the score pill and badge. Keep the card body neutral so multiple cards in a grid don't fight.
Don'tTint the whole card body by status. A grid of red cards is illegible.
DoPair color with a glyph (✓ / ! / ×). 8% of male users are color-blind.
Don'tRely on color alone for healthy/warning/critical.
DoUse compact density on mobile (gap 6, padding 12 14, score 36).
Don'tMix densities within one screen — pick comfortable OR compact.
